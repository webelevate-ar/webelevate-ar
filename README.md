Hago sitios para negocios que hoy no tienen web, o que tienen una que no les trae clientes.
Trabajo sobre todo con comercios y talleres de Córdoba: sitios rápidos, pensados para el celular
y para que la gente termine llamando, escribiendo por WhatsApp o entrando al local.

## Trabajos

### 🏍️ Carrizo Motos — [ver el sitio](https://carrizomotos-cba.vercel.app)

Taller de motos multimarca en Córdoba Capital. Reemplazo de un sitio viejo de Wix.

Sitio de una sola página, sin framework: HTML, CSS y JavaScript planos. Estética de plano de
taller — fondo oscuro, tipografía condensada, acento ámbar y retícula técnica.

Lo que tiene adentro:

- **Un plano interactivo de la moto**: se tocan los puntos y cada uno explica un tipo de trabajo,
  con su botón para consultar por eso puntualmente.
- **Asistente de consultas** que responde horarios calculados en vivo, ubicación, marcas y
  demoras, y arma el mensaje de presupuesto. No inventa precios ni plazos.
- **Una sola fuente de verdad para el horario**: el cartel de "Abierto ahora", la tabla y el
  asistente leen todos del mismo bloque de datos estructurados.
- SEO completo: datos estructurados de negocio local, preguntas frecuentes con su schema,
  sitemap, y acceso explícito para los rastreadores de IA.

### 🧽 Luffaloop — [ver el sitio](https://luffaloop-web.vercel.app)

Emprendimiento familiar de luffas vegetales de Córdoba. Sitio de 8 páginas con Tailwind,
incluidas las páginas legales según la Ley 24.240 y la Ley 25.326.

Las ilustraciones son SVG dibujado a mano en el propio código: el sitio no depende de ninguna
imagen externa y pesa casi nada.

## Cómo trabajo

- **Sin framework cuando no hace falta.** Un sitio de un taller no necesita React. HTML plano
  carga más rápido, no se rompe solo con el tiempo y el cliente puede abrirlo con el Bloc de
  notas si quiere cambiar una palabra.
- **Cada sitio se entrega con un manual en castellano** para que el dueño pueda cambiar textos,
  precios y teléfonos sin depender de mí.
- **No prometo lo que no se puede verificar.** Si el negocio no puede sostener una promesa, esa
  frase no va en la web: una reseña negativa cuesta más de lo que suma una frase linda.
